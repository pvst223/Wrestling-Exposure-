# V0.6.1 development cross-fit: prospective clarifications (recorded in the ledger as DR0 BEFORE execution)

Operation: spec_v4 02 §2.3 development protocol + 03 §3 selection, MobileCLIP-B only (frozen backbone), on the six existing development-pool clips. Development-exposed data only; every number exploratory; no outcome class is assigned. Old V0.6 TEST clips (Andrade/Mysterio, Andrade/Omega) are development data here as authorised by spec 02 §2.2–2.3 (see report: flagged for reviewer confirmation). No Holdout #2 information is accessed.

Decisions that spec_v4 left to code (all non-performance-based, all mirror the frozen strict rule; none alters the rule, grids, selection, metrics, renderer or C1–C8):
- **D1 Folds.** Leave-one-component-out folds as in 02 §2.3 (identity components via shared identities): {HBK/Benjamin}, {Orton/Rollins}, {Rock/HHH}, {Lesnar/Bryan}, {Andrade/Mysterio + Andrade/Omega}. Evaluation episodes are the frozen strict episodes of SEED_EPISODE_MANIFEST_V2 (status OK), unchanged; only 3 folds contain one (4 episodes); HBK and Rock folds contribute training data only. (02 §2.3 says "4 of 5 folds"; the manifest gives 3 evaluable folds / 4 evaluable episodes. Reported as a spec wording inconsistency; no change made.)
- **D2 Training episodes.** For every clip outside the held-out fold, its single named pair, K = 5 deterministic resamples of the TARGET seed draw (k = 0..4). Resamples are never units and are not used in any evaluation statistic.
- **D3 Seed draw.** Eligible detections = frozen eligibility (first-pass WRESTLER label, multi_person_flag 0) that also have an extracted feature (extraction manifest row present in the feature cache). Strict rule first (4 seeds, ≥2 shots, ≤2 per shot, ≥60 frames apart, box_h ≥ median of eligible detections, exhaustive DFS over a seeded round-robin order). Only if infeasible: relaxed fallback with m = 3, then m = 2 seeds (≥1 shot; still ≤2 per shot, ≥60 frames apart, same median rule). RNG key `f"{ep_seed}|{clip}|{identity}|target|k{k}"`, ep_seed = int(first 8 hex of the spec_v4 manifest hash, 16) % 2^31 (precedent: EXR2). The strict selector is parity-tested against the frozen phase1_structure.select_target_seeds.
- **D4 Referee/non-target seeds.** Frozen `select_referee_seeds` with the frozen EPISODE_SEED, identical for all k (only target seeds are resampled).
- **D5 Candidates.** Mirror of frozen build_clip: all labelled non-UNLABELABLE tracklets except those containing the episode's seed detections; y = 0/1 for the pair's identities, 2 otherwise.
- **D6 Training.** Frozen recipe via `phase1_run.train_l1` (Adam, lr 0.01, 30 epochs, torch seed 0, deterministic episode order by id, no auxiliary loss, no ensemble). One head per evaluable fold, trained on all training episodes of the other folds.
- **D7 Selection.** 03 §3 with the locked implementation: pooled out-of-fold unit tables for L1 (20-pt grid) and B0 (original 20-pt grid, scored directly on the same evaluation episodes); fold coverage = coverage within the fold (Andrade episodes pooled); joint c*; lowest pooled FTA; ties highest coverage; ties lexicographic.
- **D8 Reporting.** Pooled OOF unit FTA with exact Clopper-Pearson CIs, coverage, exploratory paired sign test (b, c, p), the locked development diagnostics at the selected L1 point (bootstrap seed = ep_seed, 2000 resamples). Heads for seeds 1–3, the final all-development head and ablations A/B are NOT run.
- **D9 Renderer.** Locked renderer applied to the out-of-fold decisions at the selected L1 operating point (private outputs; sidecars and hashes only recorded).
- **D10 Single execution.** The result file is created once (mode 0444); the driver refuses a second run unless a defect is recorded and reviewed.

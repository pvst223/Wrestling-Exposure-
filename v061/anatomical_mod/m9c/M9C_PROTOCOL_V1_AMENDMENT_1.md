# M9C PROTOCOL V1 — AMENDMENT 1 (final reviewer authorization clarifications; registered before sampling)
Replaces protocol sec. 5 (open items). Nothing else changes.
- **5a Structural per-landmark KILL clause.** A frame-level `CONTAMINATED` verdict alone does NOT satisfy it. It triggers only if localized inspection specifically establishes that one or more actually released/emitted `OWN_ONLY` landmarks (or a released bone built from them) belong anatomically to the wrong person's body, observed in **≥2 distinct shots**. If so, KILL applies independently of the ≤5% gate. The determination (`YES` / `NO` / `UNDETERMINED`, with a note) is recorded prospectively for **every** contaminated RELEASED frame after unblinding, by localized inspection of the drawn released landmarks, never inferred from the label. `m9c_join.py` takes this as an optional JSON `{review_id: {wrong_body_landmark, note}}`; until every contaminated released frame has one the outcome is `PENDING_STRUCTURAL_DETERMINATION`.
- **5b Control.** If the hard-veto control has 0 observed contamination, the ≥2× separation criterion is uninformative and NOT satisfied by vacuous arithmetic. Outcome `NOT_KEEP_CRITERION_UNINFORMATIVE_CONTROL_NEEDS_REVIEWER_INTERPRETATION` when that is the only unmet gate and no MODIFY/KILL trigger applies; another MODIFY/KILL trigger decides first.
- **5c** Any unmet KEEP gate without a prospectively defined MODIFY/KILL condition → `NOT_KEEP_CRITERION_UNMET_NEEDS_REVIEWER_INTERPRETATION`. No post-hoc outcome rule is invented.
- **Execution order (reviewer):** Claude freezes its own blind verdicts but does not open/join the key and shows nothing to the owner; the owner's blinded 50-item packet is prepared separately; S5 unblinding/join and S6 outcome calculation occur only after BOTH verdict sets are frozen. Registered join script updated for 5a/5b (tests 25/25 pass; release code unchanged).

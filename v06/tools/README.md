# V0.6 Phase 1 tooling (deterministic; no models, no training, no data)
Intended flow: ingest_clip -> make_splits -> leakage_audit -> (freeze + hash manifests) -> [feature extraction / heads: NOT built yet] -> blind_sample (pre-tracker information only) -> human labels -> commit_labels -> adjudicate -> phase1_metrics -> report_check (render from metrics.json, then verify numbers) -> pipeline_guard.freeze_dir.
registry.py logs every dev look and enforces single-use sealed test/holdout. Self-tests: python3 selftest.py selftest2.py selftest3.py (all must pass).
Notes: freeze_dir makes files read-only but root can still write; the control that matters is output_hashes.json + verify_frozen. Labels from the developer are marked independent=0. Rights status defaults to UNRESOLVED. No script reads model/tracker results except adjudicate.py and phase1_metrics.py, after the label commitment verifies.
Added: extract_features.py (hash-keyed resumable one-crop-per-candidate extraction; backbone adapters mobileclip_b and timm_local for user-supplied re-ID/DINOv2 weights) and heads.py (non-learned baseline; single linear learned head with minimal episodic A/B/NON-TARGET objective, deterministic training). selftest4.py uses synthetic features only: no real data and no identity model were trained. Do not run on footage before the preregistration is frozen.

# V0.5 pre-registered plan (written 2026-10-15, BEFORE any V0.5 tracker output existed)

Development prototype. In-sample on one clip. Nothing is validated. The criteria below are developer-set screening criteria, not validated thresholds.

## What was known when this was written
V0.4 frozen results (A): 359 emitted, 27 emissions inside known/inferred-bad frames, 2/16 viewed multi-body frames emitted, 1/18 wrong-person frames emitted, 6/21 contamination-regression frames emitted, 82 REACQUISITION_UNCERTAIN, 0 off-image predictions, cuts 20/0. Single-reviewer adjudication of V0.4 found carry-scene contamination still emitted. No V0.5 code had run.

## Mechanism to be built (architecture, not frame rules)
Landmark OWNERSHIP from per-person instance masks (YOLOv8m-seg, general COCO model, NOT wrestling-trained): each confident landmark is classified OWN_ONLY / CONTESTED / OTHER_ONLY / OUTSIDE relative to the owner mask; opponent landmarks inside the owner mask; skeleton-explains-mask test; bones that span two instances. Cross-body geometry cues (limb length, shared joints, part-identity conflict, temporal joint jump) feed ownership as vetoes. Appearance (embedding) supports IDENTITY only and can veto, never vouch, for ownership. A masked-box embedding (opponent and background pixels greyed out by the owner mask) is added as an identity cue.
Ownership states: SINGLE_BODY_SUPPORTED / MIXED_BODY_SUSPECTED / OWNERSHIP_UNCERTAIN. COM is emitted only if identity is SUPPORTED_INDEPENDENT and ownership is SINGLE_BODY_SUPPORTED and anatomy plausibility passes.

## Pre-registered report (separate dimensions, no single accuracy number)
Coverage (MEASURED/PARTIAL/PREDICTED/UNRESOLVED); identity states, appearance-dependent emissions, reacquisition events/failures, A/B ambiguity/collapse; ownership state counts; known/inferred-bad emissions (of 260); wrong-person regression (of 18); viewed multi-body (of 16); regression-case list emitted/rejected; off-image predictions; cut TP/FP; V0.3-insufficient recovery; unnecessary rejections of clean frames (sampled).

## Development discipline
Iterate only on failure CLASSES. Regression frame lists are looked at as diagnostics; no frame numbers in decision code. Every change is logged in `V0.5_CHANGELOG.md` with before/after-observation status. Freeze and hash before the single full run.

## Holdout gate (pre-registered screening criteria)
Answer YES only if ALL hold in the frozen run, otherwise NO:
1. Emissions inside known/inferred-bad frames (of 260) <= 10.
2. Viewed multi-body (of 16) emitted <= 1 and wrong-person (of 18) emitted <= 1.
3. In a fresh shuffled, status-blind sample of >= 30 V0.5 emissions that I judge, no more than 1 is contaminated (this is my own single-reviewer sample, in-sample).
4. A emitted frames >= 250 (coverage not collapsed) and at least 10 of 21 shots contain an A emission.
5. 0 off-image predictions; cuts unchanged (20 true / 0 false).
6. No documented failure class that a holdout test could not expose (e.g. a systematic silent-wrong class that remains undetectable by any V0.5 check is a NO unless it is rejected by design).
The gate is not a validation threshold. Passing it would mean only that an untouched external test is informative.

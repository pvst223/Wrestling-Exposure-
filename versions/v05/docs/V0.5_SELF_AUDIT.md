# V0.5 self-audit (developer; critical)

All numbers are IN-SAMPLE development results on ONE 50 s clip, judged by ONE non-independent reviewer. None is validation, accuracy, generalisation, clinical utility, workload, fatigue or injury prediction.

## What V0.5 changed in substance
Identity evidence (V0.4) is kept separate from landmark-ownership evidence (new person masks from a general COCO YOLOv8m-seg model). APPEARANCE_PART_COHERENT no longer counts as positive evidence (diagnostic only); appearance can only veto. A COM is emitted only if identity is SUPPORTED_INDEPENDENT, ownership is SINGLE_BODY_SUPPORTED, anatomy passes, probation passed and visible mass >= 0.4. TEMPORAL_CONTINUATION is never emitted. IDENTITY_CONTRA_CUE no longer allows prediction.

## Main weaknesses (honest)
1. **Merged-mask contamination is not detectable from single-frame evidence.** In carry scenes (f931-957 etc.) the segmenter returns one merged mask with no second detection inside it. Only a temporal "opponent/third person presumed absorbed" rule catches this. That rule was designed AFTER seeing these very frames (D15-D17), so the in-sample gain proves nothing about generalisation. A new interaction type with a different history could pass silently.
2. The mask model is general COCO, not validated here; masks were resized from a letterboxed tensor (possible ~2 px vertical edge error, D14).
3. The absorbed-state rule is conservative: 87+30 A frames withheld, some of which were clean (E4: 8 of 12 clean). Coverage cost is real.
4. Embeddings are a general model (MobileCLIP-B), not person ReID; cosine scores are not probabilities. 35 emitted frames needed the embedding (colour alone R < 0.8); none in known-bad, but that is a small in-sample check.
5. Constants: UNEXPL_DIST_S 0.4 came from a rule fixed beforehand using only clean seeds; others were inherited or set pre-run. Three dev runs were observed before freeze (D15-D18); the formal run is the fourth execution and is byte-identical on re-run.
6. Frame 1080 (kneeling over opponent) and frame 617 are emitted inside known/inferred-bad ranges; 1 wrong-person frame remains emitted (at the pre-registered threshold, not below it).
7. "Known-bad" includes inferred extents of never-viewed frames; ground truth is a single reviewer's judgement, not independent.
8. Seed frames (25, 99, 200, 550, 620) are excluded from the viewed-CLEAN metric but still shape identity centroids.

# V0.5 holdout gate

Question: is V0.5 ready to be tested UNCHANGED on unseen holdout footage? (A readiness judgement, NOT validation.)

## Pre-registered criteria (docs/V0.5_PREREGISTERED_PLAN.md) vs result
| Criterion | Result | Met |
|---|---|---|
| known/inferred-bad emitted <= 10 of 260 | 2 | yes |
| viewed multi-body emitted <= 1 of 16 | 0 | yes |
| wrong-person emitted <= 1 of 18 | 1 | yes (at limit) |
| fresh status-blind sample >= 30 emissions, <= 1 contaminated | 40 sampled (30 A + 10 B), 0 contaminated, 3 unsure | yes (single reviewer) |
| A emitted >= 250 and emission in >= 10 of 21 shots | 309; 10 of 21 | yes (shots at limit) |
| 0 off-image predictions; cuts 20 true / 0 false | 0; 20/0 | yes |
| no systematic undetectable silent-wrong class remaining | merged-mask carry contamination is undetectable from single-frame evidence; caught only by a temporal rule designed on those same frames | **NO** |

## Answer: **NO**
Not ready. All numeric thresholds are met in-sample, but the last pre-registered criterion fails: a known class of silent-wrong measurement (two bodies in one merged mask) has no independent per-frame detector, and the rule that catches it was fitted to the observed frames, so its behaviour on new footage is unknown and could be silently wrong. Per the project's fail-closed rule the gate is not forced to YES.

Also relevant: a single non-independent reviewer, one clip, coverage 10/21 shots at the limit, 1 wrong-person frame at the limit.

## What would change the answer (not done; no V0.6 here)
- Independent per-frame evidence for merged bodies (e.g. a stronger or fine-tuned instance/pose model), or
- an independent reviewer plus frozen-rule testing; the holdout should only be used once and without changing code afterwards. If the user still wants to run holdout unchanged, treat results as exploratory.

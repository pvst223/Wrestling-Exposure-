# V0.5 status and confidence definitions

None of the numbers below is a probability of correctness or a validated confidence. There is deliberately NO single combined confidence value.

## Status (per wrestler, per frame)
| Status | Meaning | Required |
|---|---|---|
| MEASURED | A COM was computed from landmarks the system supports as belonging to this wrestler | identity SUPPORTED_INDEPENDENT with tier HIGH; ownership SINGLE_BODY_SUPPORTED; anatomy plausibility PASS; probation passed; visible mass >= 0.85 with the trunk visible |
| PARTIAL | As MEASURED but limited | same gates except: visible mass 0.4-0.85 or no trunk (LOW_MASS) and/or identity tier ACCEPT (IDENTITY_TIER_ACCEPT) |
| PREDICTED | Position extrapolated from the last MEASURED anchor. NOT a measurement and not anatomy | anchor <= 6 frames old, no taint/ambiguity/contra/ownership failure, inside the image and anchor-box bound, uncertainty radius <= 0.5 box diagonal |
| UNRESOLVED | Nothing emitted. `unresolved_reason` says why (fail closed) | - |

## Evidence dimensions (separate columns)
* **IDENTITY EVIDENCE** (`identity_state`, `identity_tier`, `ind_S`, `ind_R`, `ind_n_cues`, `anti_identity_margin_g`, `joint_assignment_margin`, `reid_*`, `colour_*`, `masked_box_*`): `ind_S` in [-1,1] is a reliability-weighted mean of cue supports (HEURISTIC similarity-margin score, not a probability); `ind_R` is summed cue reliability (heuristic, from the 10 seed crops); `n` counts cues with reliability >= 0.25. Tier HIGH = S >= 0.5, R >= 1.5, n >= 3.
* **CONTINUITY / POSE** (`continuity_*`, `pose_consistency_S`, `temporal_credit`): supporting tracking evidence only; never identity verification.
* **OWNERSHIP EVIDENCE** (`ownership_state`, `ownership_reasons`, `own_only_frac`, `contested_frac`, `other_only_frac`, `outside_frac`, `opponent_landmarks_inside_mask_frac`, `mask_unexplained_frac`, `bones_*`): fractions are of confident landmarks (or of mask area); heuristic segmentation-based indicators, not a probability.
* **ANATOMICAL PLAUSIBILITY** (`anatomy_plausibility`, `anatomy_reasons`, `cross_body_cues`): PASS/FAIL against geometric/temporal sanity checks.
* **COM SUPPORT** (`com_eligibility`, `com_ineligible_reason`, `visible_mass_fraction`, `com_segments_used`, `com_landmarks_used`): `visible_mass_fraction` is the fraction of the Dempster body mass table whose segments are visible. It is NOT accuracy.
* **PREDICTION** (`frames_since_anchor`, `prediction_uncertainty_px`): the radius is a heuristic (0.1 + 0.1 k) x anchor-box diagonal, not a statistical interval.

# V0.5 model selection (new model introduced: person instance segmentation)

* **Model:** Ultralytics YOLOv8m-seg, COCO-pretrained, 'person' class only. Weights file `yolov8m-seg.pt`, sha256 `51fa7e5ef385efa6d5b1d8e31b73399be6ed5d7ca71bda4bd4b2794bb445c4f4`, 54,921,020 bytes, from `https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8m-seg.pt` (reachable from this workspace; weights not included in the package, the hash and URL are). Ultralytics licence is AGPL-3.0 (code and weights); check that it suits your use.
* **Why:** it is the only technically reasonable per-person region evidence obtainable here (other model sources are blocked; see `v04/docs/V0.4_REID_MODEL_SELECTION.md`). It lets landmark ownership be tested against person silhouettes instead of appearance.
* **Settings:** imgsz 960, conf 0.10, classes=[0], CPU; masks thresholded at 0.5 and cached at 320x180 (bit-packed). Instances with confidence < 0.25 are ignored by the tracker.
* **Pretrained domain / limits:** COCO everyday scenes. Not trained for wrestling, bent/grounded/airborne poses, motion blur, 640x360 broadcast video or overlapping bodies. Instance masks of touching people may merge, split arbitrarily, or leak across people. Masks are not validated against any ground truth here.
* **Reproducibility:** inference is deterministic on CPU for fixed weights/version (ultralytics 8.4.177, torch 2.14.1); the mask cache is shipped so the tracker run does not depend on re-running segmentation.
* **MobileCLIP-B** (identity embedding) is unchanged from V0.4 (general image embedding, NOT person-ReID; cosine similarity is an uncalibrated heuristic; seeds tiny). V0.5 adds only a masked-box crop type using the same encoder. Weights: Ultralytics `mobileclip_blt.ts` sha256 `a67804d1b0f07b8b9a20c1761ec0847f34660f5fa338ec70e8f3fce68ed95e54`; Apple MIT code vendored; weights under Apple's model licence.
